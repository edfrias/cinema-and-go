# Cinema and Go Docs

This folder centralizes roadmap documentation, refactor plans, architectural decisions, and shared references for the monorepo.

## Structure

- `roadmap/`: phases, backlog, and validation criteria by stage.
- `implementation/`: refactor guides and current-state vs target-state material.
- `adr/`: Architecture Decision Records.
- `reference/`: editorial rules and shared references.
